Qt Book Code Samples
=====================

Source
------
These code samples are based on the "Qt 6 QML Book" (also known as the "QML Book"),
an open-source book about Qt Quick and QML development.

The book is available online at: https://qmlbook.github.io (Qt5 version)

The Qt6 version is here: https://www.qt.io/product/qt6/qml-book

Projects
--------
- console_app/          - Qt Core console application examples
- hello_world/          - Basic QML "Hello World" application
- qwidget_app_2/        - QWidget custom widget with mouse interaction
- qwidget_desktop/      - QWidget desktop application
- 05_drawing_shapes/    - QPainter drawing examples
- 06-qwidget_desktop_sql/ - QWidget application with SQL database
- qml-01/               - QML basic components (buttons, shapes, text input)
- 97-qml/               - QML application example
- 98-qml/               - QML application example

Notes
-----
- Examples cover both QWidget (traditional) and QML (declarative) approaches
- Mix of Qt 5.15 and Qt 6 code samples
- Demonstrates core Qt concepts: signals/slots, painting, mouse events, layouts
- SQL examples use SQLite database
